What it does

Every package manager. One window.

6 package managers

Homebrew formula and cask, npm (nvm-aware), pip, Cargo, and RubyGems — all scanned in parallel on launch.

Dashboard strip

Live tiles at the top of the sidebar: Total, Updates, New (last 7 days), Orphans. Each tile taps into the matching filter.

Update detection

Parallel update check across all sources. Update a single package or run Update All with one confirmation.

Inline changelog

Version history fetched from GitHub Releases or registry APIs per package. Stable releases only, no browser needed.

Collections

Group packages into named collections with custom SF Symbol icons and colors. Persisted locally to ~/.pkglens/.

Orphan detection

brew leaves-based orphan flagging, stale-package detection (90+ days), and bulk-remove with one confirmation sheet.

In use

From scan to action in a single window.

Privacy

Local-only by design.

  • No telemetry, accounts, or cloud sync of any kind.
  • All data stays on your Mac — notes and history in ~/.pkglens/.
  • Package metadata is fetched from public registries only when you explicitly check for updates or changelogs.
  • Open source, native SwiftUI, zero third-party dependencies.
